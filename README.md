### What I do

Bring a reference — an app you admire, screenshots or a screen recording.

1. **Recreate** the screens and flows you choose, with the original's typography, spacing, colour and interactions.
2. **Make it interactive** — real components, text and state, running in the browser rather than a clickable picture.
3. **Hand over the source** — Expo, React Native and TypeScript, with a DESIGN.md that documents the design system.

Useful for pitches, client demos, and aligning a team on how an interface should look and behave before development starts.
